# 伦理与使用规范（Ethics & Acceptable Use）

> 本项目仅用于**防御、研究与教育**。

## 我们做什么
- 在**沙盒**中演示：访客扮演骗子，机器人扮演“潜在受害人”，展示拖延策略与情报提取。
- 为反诈研究者、志愿者、机构提供可审阅、可复用的开源组件（提取器、话术分类器、脱敏模块、人设引擎）。

## 我们绝不做什么
- **不主动联系任何真实的人**：不外呼、不群发、不主动私信、不加好友。
- **不提供真实信息**：不给出真实验证码、卡号、密码、身份证号，不真实转账。
- **不报复、不曝光**：不人肉、不公开曝光个人信息、不“以骗制骗”、不攻击或入侵任何系统。
- **不留存原文**：前端只在页面内存中处理原文；展示、导出、发送给大模型的内容都先经过脱敏。

## 部署到真实渠道之前（电话、IM、诱饵号码）
1. 仅使用**自有或经授权**的号码/账号，明确其诱饵用途。
2. 评估并遵守《个人信息保护法》《反电信网络诈骗法》《网络安全法》以及电信、录音相关规定；必要时咨询法律意见。
3. 最小化留存：只保留防诈所需的脱敏指标，设置保留期限与访问控制，保留审计日志。
4. 情报优先提交给官方渠道（110、96110、国家反诈中心 APP、银行/支付平台风控），而非公开发布。
5. 对误报保持谨慎：提取结果只是线索，不能据此对任何人作出认定。

## 遇到诈骗
立即停止转账，拨打 **110** 或 **96110**，并保留证据。


## 公开情报库（v0.2 起）

DeepSuck 会公开发布收集到的诈骗情报，规则见 [INTEL.md](INTEL.md)：

- 诈骗电话、钱包地址、网址 / APP、话术**完整公开**——它们是诈骗基础设施；
- 银行卡号、姓名、身份证号、个人账号**部分打码**——收款卡常属于被冒用、被利用的普通人；
- 只收录诈骗方主动暴露的信息，不收录受害人信息；任何人可凭条目 ID 申诉下架；
- 公开情报库是公益补充，不替代报警；请优先向 110 / 96110 / 国家反诈中心 App 举报。
