它如何工作

五个环节，全部在你的浏览器里完成（规则引擎）；接入大模型时，发给模型的内容也已先在本地脱敏。

01

诱敌

以“潜在受害人”的人设出现：反诈部署方可将其接到诱饵号码或举报转接渠道。机器人从不主动联系任何真实的人。

02

周旋

故意误解、请求重复、假装手机卡顿、去找老花镜……每一轮都在消耗骗子的时间与精力。

03

提取情报

识别银行卡、手机号、QQ/微信/支付宝、BTC/ETH/TRON 地址、网址，以及“安全账户”“索要验证码”等话术。

04

脱敏

所有情报在展示与导出前统一打码，如 6222 **** **** 1234、138****5678、0x12ab...9f3e。

05

预警

汇总成结构化情报报告（JSON），未来可对接反诈平台、银行风控与社区预警（规划中）。

零成本，开箱即用

默认的规则/模板人设引擎完全运行在浏览器中，无需任何 API Key、无需服务器，可直接托管在 GitHub Pages、Cloudflare Pages 或阿里云 OSS。

想要更自然的对话？可选接入阿里云百炼（通义千问 qwen-plus）或任何 OpenAI 兼容的国产大模型：自带一个零依赖的 Node 小后端做代理，API Key 只放在你自己服务器的 .env 里，不暴露给浏览器。默认关闭。

git clone <repo> deepsuck && cd deepsuck
# 1) 纯静态（无需 Key）
cd site && python3 -m http.server 8080

# 2) 可选：接入通义千问（百炼）
cp .env.example .env
# 编辑 .env，填入 DASHSCOPE_API_KEY=sk-...
npm start      # http://127.0.0.1:8787

底线与使用声明

DeepSuck 只用于防御、研究与教育。以下底线写进了代码，也写进了贡献规范。

  • 不主动出击：机器人从不主动联系任何真实的人，只应对主动找上门的诈骗方；演示中由访客自己扮演骗子。
  • 默认脱敏：所有账户、电话、地址在展示与导出时都经过脱敏模块打码；原文只存在于当前页面内存中，不上传、不落盘。
  • 不提供真实信息：人设永远不会给出真实的验证码、卡号、密码或身份证号，大模型输出也会经过安全过滤。
  • 不“以暴制暴”：禁止用于骚扰、人肉、报复、“反向诈骗”或任何违法用途；不攻击、不入侵任何系统。
  • 交给专业力量：发现诈骗请拨打 110 或全国反诈专线 96110，并通过“国家反诈中心”APP 举报。情报仅作为线索参考。
  • 合规优先：接入真实渠道（电话、IM）前，请评估《个人信息保护法》《反电信网络诈骗法》等法律要求，并取得必要授权。
