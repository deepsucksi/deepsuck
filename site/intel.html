公开诈骗情报库

DeepSuck 会公开发布它收集到的诈骗情报：诈骗电话、加密钱包地址、诈骗网址 / APP 名称、话术套路完整公开，方便任何人检索、拦截与预警；银行卡号、姓名、个人账号只部分公开——很多收款卡属于被冒用、被利用的普通人。

当前库中全部为 示例数据（虚构号码、无效地址与 RFC 2606 保留域名 .example），用于展示格式与功能，不对应任何真实个人或网站。真实情报经审核后才会收录。

发布策略

完整公开

  • 诈骗电话（含 400/800、座机、改号来电显示号码）
  • 加密货币钱包地址（TRON / ETH / BTC 等）
  • 诈骗网址、域名，诈骗 APP / 平台名称
  • 话术与手法模式（不含受害人信息）

这些是诈骗分子的“基础设施”，公开得越快越完整，越多人能在接到电话、点开链接之前识别它。

部分打码

  • 银行卡号：按 PCI DSS 只留前 6 位（BIN）与后 4 位，如 622202*********1234，并标注开户行及 BIN 推断的发卡行、卡种
  • 收款户名 / 姓名：只留姓，如 王**
  • 身份证号：110101********1234
  • 支付宝 / 微信 / QQ / 邮箱等个人账号：首尾各留 2 位

大量“跑分卡”“收款卡”属于被冒用身份、被诱骗出租或出借账户的普通人（不少是学生和老人）。部分打码既能帮助比对，又不至于让无辜者被网暴。

  • 只收录诈骗方主动暴露的信息：不收录受害人信息，不做“人肉”，不对任何号码发起骚扰或“反击”。
  • 每条可溯源：标注首次/最近出现时间、场景、话术标签、举报次数与来源（沙盒、社区提交、自有诱饵号码）。
  • 示例与真实分开：示例条目一律标注 example: true 与「示例数据」。
  • 情报仅供参考：号码可能被回收、改号或冒用，不能作为定罪依据；请以公安机关认定为准。

下架与申诉

如果你认为某条情报错误收录了你的号码、账户或网站（例如号码被回收再分配、银行卡被他人冒用、域名已易主），请提交下架申诉：

  1. 打开 GitHub 下架申诉模板，只需填写条目 ID（如 EX-0001），无需公开你的任何个人信息；
  2. 维护者收到后会优先处理：先将条目标记为 disputed（页面隐藏具体值），核实后下架（removed）或恢复；
  3. 若涉及隐私不便公开说明，可在申诉中注明，维护者会提供非公开的沟通方式。

如你的银行卡被冒用于诈骗收款，请同时尽快联系发卡银行并向公安机关报案说明情况。

遇到诈骗，先报警、再举报

110 / 96110

已经转账或正在被骗：立即拨打 110 报警，并联系银行尝试止付。96110 是全国反诈预警劝阻专线，接到 96110 来电请务必接听。

国家反诈中心 App

在官方应用商店搜索“国家反诈中心”安装。首页“我要举报”可提交诈骗电话、短信、网址、APP、收款账户等线索，还能开启来电/短信预警。

其他渠道

垃圾短信/骚扰电话/不良网址可向 12321（网络不良与垃圾信息举报受理中心）举报；网络违法犯罪线索可通过公安部网络违法犯罪举报网站提交。

DeepSuck 的情报库是公益补充，不能替代报警。请优先通过以上官方渠道举报。

提交情报

01

整理

打开沙盒，选择最接近的场景，把骗子发给你的原话逐条粘贴进去（或在“骗子”位置复述）。提取与打码全部在你的浏览器本地完成。

02

生成

点“结束对话 · 生成情报看板”，再点 “提交到情报库”：会按发布策略生成提交内容（电话/地址/网址完整，银行卡/姓名已打码）并复制到剪贴板。

03

提交

在打开的 GitHub 情报提交模板中粘贴并补充时间、渠道，维护者审核后收录。请勿提交受害人信息或沙盒里的虚构样例。
